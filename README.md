## Features

- Windows Forms desktop application
- Enter an equipment name
- Choose Electronic or Non-Electronic
- Click Add Equipment to display it in a temporary list
- Empty equipment names are rejected

## Features not yet implemented

- Equipment classes, handling instructions, and individual equipment IDs
- Student registration
- Administrator account and login
- MySQL database and permanent storage
- Borrowing, returning, requisitions, and overdue history
- Dashboard

## Run

```powershell
dotnet run --project EquipmentProj.csproj
```
